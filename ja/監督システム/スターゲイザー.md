# スターゲイザー 監督システム

### 「運勢占い」

場所：屋外エリア / 娯楽エリア

緊急度：⚠

多くのコンビクトと局員がスターゲイザーのところに集まって、自分の運勢を知りたがっている。

- 私の運勢も占ってくれ

### 「不思議なアロマ」

場所：屋外エリア / 娯楽エリア

緊急度：⚠

最近、管理局によく不思議な匂いが漂っている。

- 調べに行く

  スターゲイザーが普段使っているアロマのようだ。

### 「難解な予言」

場所：屋外エリア

緊急度：⚠⚠

管理局の廊下で、あなたはスターゲイザーに会った。

スターゲイザー：あら、あたしの化け物ちゃん。未来を占って欲しい？


【选项1】

- 占ってもらう

- 遠慮しておく


スターゲイザー：遠慮しないで。さぁ、あたしの手を握って、一緒に未来を感じて。

スターゲイザー：ふーん……あなたが進む先に、生まれたばかりの朝日があるわ。

スターゲイザー：あなたが持つ黒い鏡は、その光によって照らされる。

スターゲイザー：鏡の裏には、全ての喜びと悲しみが刻まれている。

スターゲイザー：偽りの境界線を超えて、その彼方に辿り着けるわ。

- まったく意味不明だが

  スターゲイザー：ふふ、気にしないで。あなたならいつか分かるわ、親愛なる化け物ちゃん。

### 「「下手」なプレイヤー」

場所：娯楽エリア

緊急度：⚠⚠

ダンスゲームをプレイしているスターゲイザーの周りで、何人かのコンビクトと局員が見物している。

踊るスターゲイザーの姿はとても素敵で神秘的であり、思わず見入ってしまう。

- みんなと一緒に見る

  全ての動きはリズムに乗っていたが、ゲームのタイミングからは見事に外れており、得点はひどかった。

  一曲が終わった後、スターゲイザーのスコアは最低評価しか得られなかった。

  しかし、周囲からは絶えることのない拍手が送られた。

### 「心の色」

場所：暗室

緊急度：⚠⚠⚠

スターゲイザー：あら、あたしの化け物ちゃん。ようやく来たわね。

スターゲイザーは静かに暗室の隅に座っていた。あなたが来ることを予想していたようだ。

- 疑問を呈する

  局長：どうして私がここに来ると知っていた？

  スターゲイザー：忘れないで欲しいわ。あたしはスターゲイザー。未来を予知することができるの。

  スターゲイザーがいつもの通りあなたに近寄ると、不思議な香りがあなたの鼻をくすぐった。

  スターゲイザー：ふふ……見えてきたわ。今日、あなたの心は淡い紫。砂の海の夕暮れと同じ、あるいは、月光が反射している蛇の鱗のような色よ。


  - 質問する

    局長：昨日、私の心は水色だと言っていたが……

    スターゲイザーは自分の指をあなたの唇に当てた。

    スターゲイザー：シーッ、人の話はしっかりと聞くものよ。「誰も同じ川に二度入ることはできない」という言葉を知らないかしら？人の心も同じ。その色は日々異なるのよ。

    スターゲイザー：そうよ、その疑問は口に出さないで。

    スターゲイザー：また明日、どこかで会えるかもしれないわ。その時に、あなたの心の色がまだ清らかでいられるといいわね。

  - 信じる


  <br>

  スターゲイザー：ふふ、局長も自分の心の色が気になるのかしら。

  スターゲイザーが手を伸ばして、あなたの髪を整えてくれた。

  スターゲイザー：では、また明日ね。

  スターゲイザー：明日のある時、ある場所で、あなたを待っているわ。

### 「砂の海の白狐」

場所：温室

緊急度：⚠⚠⚠

温室で花の世話をしている時に、スターゲイザーがそっと近づいてきた。

スターゲイザー：局長、また会えたわね。「砂の海の白狐」という物語をご存じかしら？

- 聞かせてくれ

  スターゲイザー：砂の海で、道に迷った一人の旅人がいたの。水も食料も、もう尽きかけていた。

  スターゲイザー：すると、一匹の白い狐が現れたわ。狐は自分を食べて、この砂の海から脱出してくれと旅人に提案したの。

  局長：それで？

  スターゲイザー：その後の話は、あなたはどうなると思う？旅人は白狐を食べたのかしら？


  - 食べた

    スターゲイザー：そう。旅人はどうしても生きたかったから、白狐を食べて、無事に砂の海から戻ったわ。

    スターゲイザー：それから何年も経ち、旅人はやがてマフィアのボスになったわ。彼の手は罪悪に染まり、二度と戻ることはない。

    スターゲイザー：そして、彼は知ってしまったの。あの日、自分が食べたのは狐ではなく、自分の魂に残された僅かな善良さだったのだと。

  - 食べなかった


  <br>

  スターゲイザー：そう。旅人は自分の欲を抑えて、残り僅かな水と食料を白狐に与えたわ。

  スターゲイザー：どうせこの砂の海から出られないなら、残った物資を白狐に分け与えようと、彼はそう考えたの。

  スターゲイザー：その後、旅人の消息を知る人はいないわ。でも、それから誰かが砂漠で道に迷った時、一匹の不老不死の白狐が現れて、道に迷った人々を導いてくれるという話よ。
