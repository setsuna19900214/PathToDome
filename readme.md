# PathToDome

《无期迷途》文本资源整理项目，从官方资源中抽取文本，以 Markdown 格式提供多语言阅读和检索。命名来自于游戏英文名 <u>PathTo</u>where 与主线章节苍蓝穹顶日文译名 蒼藍<u>ドーム</u>（dome）。



## 当前提供的文本资源类型：

- 主线、活动剧情（含无尽梦魇、诡境余音、深域迷廊系列）。
- 禁闭者档案、聆听、审查、梦境和人格色谱。
- 监管系统、情绪检测及派遣文本。

## 阅读说明

[附录](附录.md)介绍选项标记、分支层级、主角文本差异，并提供禁闭者五语言名称对照表。

各语言使用游戏资源中的原文。不同语言资源由于区服更新进度存在差异；剧情路线并列展示，阅读时可能提前获知后续内容。
