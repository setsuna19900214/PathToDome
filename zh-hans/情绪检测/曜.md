# 曜 情绪检测

### 第1条

[曜似乎对大厅一侧的暖光灯产生了兴趣。 ]

曜：这是……凡尘对太阳的模仿吗……虽然……相当拙劣……

- 也可以算是……等等，别破坏灯罩啊！

  曜：拂除虚妄的外壳……竟是这样小的光点……

- 不，这只是照明用的。

  曜：是吗？和故乡的……并不相似……

### 第2条

[曜一直认真地盯着窗外。]

曜：你来了……要和我一起吗……

- 你这是在……看风景？

  曜：观日……可晓天象，识兴衰……

- 好啊，你看出了什么？

  曜：华光温耀，泽而不罹……近期，不会有天灾。

### 第3条

[某处街头正在布置灯会，彩灯已初具雏形，工匠与行人来来往往。]

曜：灯会，正在准备中……你更喜欢什么样的灯笼？

- 亮一些的。

  曜：愿意照亮夜晚的灯，才更容易被人记住。

- 你拿着的那种款式就很好看。

  曜：……这盏灯就送给你了。新年快乐，局长。
