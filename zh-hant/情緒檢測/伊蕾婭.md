# 伊蕾婭 情緒檢測

### 第1條

[伊蕾婭正站在閱覽室的書架前，眼神失望地掃過一排排書。]

伊蕾婭：「這些書全是些陳詞濫調。有沒有刺激一點的？」

- 你對鬼故事有興趣嗎？

  伊蕾婭：鬼？這世界上本就沒有鬼，不過是人們挖空心思堆砌出來的廉價恐懼罷了，人心……可比鬼恐怖。

- 這裡有本推理小說，講的是一群人各自復仇的故事。

  伊蕾婭：哦？聽起來有點意思。也是，人與人之間的欺騙和殺意，比罪案本身更有懸念。

### 第2條

[伊蕾婭正在拼積木。她正要把最後一塊積木放上去，卻轉頭看向了你。]

伊蕾婭：「來，幫我完成最後一步吧。」

- 那我就照著示意圖來吧。

  伊蕾婭：唉……真是無趣。你乾脆就留著它吧。

- 那我就隨便放囉？

  伊蕾婭：果然，你從來不會選擇無聊的做法。
