# 多芙 監管系統

### 「信件收藏」

多芙房間的儲物櫃裡一直存放著一疊有些泛黃的舊信件，她時不時會將它們取出來小心翼翼地重新閱讀。

- 這是對她來說很重要的東西吧

### 「復古風潮」

在多芙的鼓動下，管理局裡越來越多的人加入了寫信的隊伍，她的送信業務也越發興旺。

- 蠻好的

  局長：今天又會收到什麼樣的信呢？真是令人期待啊。

### 「讀書分享」

管理局裡幾位愛讀書的禁閉者會定期舉辦讀書分享活動，多芙分享了一本破舊的生活百科，並對裡面的內容倒背如流。

多芙：手機放在枕邊會有輻射，喝反覆燒開的水會中毒……

- 怎麼聽起來不太可靠呢？

### 「以退為進」

【系統通知】監管系統：

禁閉者多芙疑似在留影室與人發生衝突，是否前往查看？

- 是

  你朝著監管系統提示的方向走去，遠遠看見一位MBCC的工作人員正手叉著腰向剛從留影室出來的多芙興師問罪。

  工作人員：總算找到你了，你在這裡做什麼？我的文件呢？

  多芙：我剛剛去裡面幫一位寄信人拿她要寄的照片……

  多芙：你先別急，你的文件是什麼文件？

  工作人員：怎麼可能不急！採購部的單據和發票，明明中午就該送來的，為什麼我到現在還沒收到？

  多芙眨了眨眼睛，露出了一個恍然大悟的表情。她俯身在自己的郵差包裡反反覆覆翻找了好久，總算是找到了那個被自己遺忘在角落的信封。

  多芙：……

  看到這裡你也大概明白過來是怎麼回事了，為避免衝突的發生正準備上去勸說，卻只見已經意識到自己犯了錯的多芙將信封雙手遞給對方，滿懷歉意地向她一鞠躬。

  多芙：這位小姐，真的對不起，我、我實在不該讓您等那麼久……

  多芙：只是我今天收的信實在太多了，我從早上六點開始腳不沾地地送到現在，連午餐都沒吃。

  多芙：我已經盡力趕過來了，但還是讓您失望了……都是我的錯！

  工作人員：呃……我只是有點急了，畢竟這是我的工作……

  這一番誠懇的道歉和她語氣中的愧疚自責顯然已經讓這位年輕的工作人員有些無法招架了。但多芙吸了吸鼻子，仍在繼續。

  多芙：當然，這些都不是藉口！無論如何，很抱歉耽誤了您的工作，您如果要投訴我也是應該的。

  多芙：……不、不用您來投訴，我現在就去投訴我自己！我會自己去向局長領罰！去關禁閉！

  多芙越說越激動，跺了跺腳轉身要往你辦公室的方向走，卻反倒被工作人員一把拉住了。

  工作人員：等等，也、也沒有那麼嚴重啦……我只是一時生氣，沒有要投訴你的意思！畢竟大家都不容易嘛！

  聽了這話，多芙露出了一個驚喜又惹人憐愛的微笑。

  多芙：謝謝您的理解，我好感動……您真是個好人！要是所有人都能像您一樣善解人意的話就好了！

  多芙已經告別這位年輕的工作人員繼續送信去了，只剩拿著信封的後者還愣愣地站在原地。

  工作人員：多芙她每天要送那麼多信，已經那麼辛苦了，我不僅一點都不體諒，還這樣凶她……唉，我還真不像話！

  工作人員：對了，她剛剛是不是說她還沒吃午餐？這不行，她這麼辛苦會餓暈的，我得去買點吃的帶給她……

  局長：……

  局長：看來我的擔心是一點必要也沒有啊。

### 「植物殺手」

多芙正蹲在溫室一角盯著擺在那裡的幾個花盆，看起來似乎有些苦惱。

- 上前詢問

  局長：多芙，你怎麼了？

  多芙：啊，局長……是這樣的，我上個星期剛買了兩盆蘭花回來。

  多芙：我天天都在細心照料它們，但不知道為什麼它們看起來好像不太好……

  多芙一邊說一邊指了指腳邊的兩盆植株。

  你定睛一看，只見白色的小花幾乎都要落光了，本應是碧綠色的葉片現在也乾枯發黃。

  局長：呃……你是怎麼照顧它們的？

  多芙：我全都是嚴格按照它附贈的養護指南做的。

  多芙：蘭花喜明亮但要避免強烈的陽光直射，所以我把它們放在花房背陰處的角落了。

  多芙：澆水的頻率控制在一週兩次，花盆裡用的也是透氣性良好的蘭花專用土。

  局長：……聽起來好像確實沒什麼問題？

  多芙嘆了口氣，有些沮喪地垂下頭。

  多芙：唉，以前在家的時候我就總也做不了農事。我種的莊稼不是枯死就是歉收，我養的動物也是，用不了多久就都從圈裡逃光了。

  多芙：可能我就是跟這些動物植物不太合得來吧……真可惜，我很喜歡這兩盆蘭花的……

  - 安慰

    局長：先別難過，不如把花交給堇看看吧，應該還有救。

    局長：下次你照顧花卉的時候，不如叫上她一起，讓她當場看看你的手法上有沒有什麼問題？我想她應該會很願意幫助你。

### 「戀舊」

今天下午天氣很好，灑滿陽光的放風區空地上，多芙正在擦洗她的腳踏車。

- 過去幫忙

  局長：多芙，在洗車嗎？

  你走上前去，十分自然地接過多芙手裡的抹布，開始幫她擦洗腳踏車架。

  多芙：哦，是局長呀。

  多芙：今天沒有信要送，難得可以休息，就想著乾脆趁這個時間把我的腳踏車清洗一下，順便上點油。

  多芙對你感激地笑笑，拆下鏈條浸泡在清潔劑裡，拿起毛刷清理起了腳踏板狹縫裡的灰塵。

  這是你第一次近距離觀察多芙的腳踏車，你注意到它似乎已經很舊了，把手和坐墊磨損嚴重，車架上的油漆也剝落了不少。

  局長：這輛車你用了很久了吧？怎麼不乾脆去買一輛新的？

  多芙：這麼多年來我騎的一直都是這輛車，早就習慣了。它還能用呢，也沒必要買新。

  多芙：而且這輛車……當初是爸爸媽媽替我弄來的。

  多芙：他們留下的東西並不多，所以如果要把這輛車換掉的話，我還真有些不太捨得。

  局長：原來是這樣……

  多芙：好啦局長，多謝你的幫忙，車架已經擦完了，剩下的事我自己做就行，你回去忙吧。


  - 回去

    局長：那好，我就先回去了。

    局長：如果需要幫忙的話，隨時找我。

    告別了多芙，你走回辦公室的路上，還一直在琢磨剛剛腳踏車的事。

    局長：剛才好像看到鏈條和幾個齒輪都有點生鏽了？

    局長：回去以後向採購部提個申請吧，買些新的零件，下次幫她換上……

  - 留下


  <br>

  局長：沒事，反正今天我也沒什麼事，就留在這裡繼續幫忙好了。

  局長：接下來還要擦哪裡？

  多芙：那就恭敬不如從命啦，麻煩局長幫洗好的鏈條上一下潤滑油……

  你們一起忙碌了一個下午，總算是完成了全部的清潔工作。

  太陽西沉時，多芙在草地上騎著重新組裝好的腳踏車，她微笑著向你揮手的樣子就像一隻自由的小鴿子。
