# 이그니스 정서 검사

### 1번째 기록

[캐러멜 푸딩을 가지고 이그니스를 찾아왔다]

이그니스: 당신은… 날 보러 온 거예요?

- 맞아. 캐러멜 푸딩도 가져왔다니까

  이그니스: 흥, 흥… 거짓말 좀 작작 해요. 그리고… 당신한테 감사하지도 않아요.

- 얌전히 지내는지 보려고

  이그니스: 난 옛날의 이그니스가 아니에요! 얕잡아 보지 말라고요!

### 2번째 기록

[관리국 주방, 이그니스가 계속해서 한숨을 쉬고 있다]

이그니스: 아이고… 요리는 대체 어떻게 하는 거예요?

- 또 부엌을 태워 먹었니? 요리는 켈빈 혼자 해도 충분할 것 같은데

  이그니스: 두고 봐요! 본때를 보여주겠어요!

- 내가 도와줄게. 차가운 음식을 좀 만들면 될 것 같아. 넌 보조만 해

  이그니스: 안… 안되는 건 아니고, 완성하고 나서 내가 먼저 먹어볼게요!
